# Color Picker

A simple color picker developed as part of an internship assignment for CleanManager.

## Features

- Popup-based color picker with 12 predefined colors.
- Selection between three different shapes.
- Visual highlighting of the selected color and shape.
- Custom HEX color input with validation.
- Synchronization between the selected color and HEX input.

## Technologies

- React
- TypeScript
- SCSS
- Vite

## Getting Started

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build the project for production:

```bash
npm run build
```

Run ESLint:

```bash
npm run lint
```
